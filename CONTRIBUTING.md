# Contributing

This store publishes only apps made or reviewed by its maintainer. It does not accept app submissions:
pull requests that add or change an app are closed. The reason is the device's safety, not a lack of
interest: every package a Cardputer installs is signed by one offline key, after its source has been read.

Bug reports and ideas are welcome as issues. Security problems: see [SECURITY.md](SECURITY.md).

The rules every app follows are in [docs/rules.md](docs/rules.md); the catalog and package format in
[docs/format.md](docs/format.md).
